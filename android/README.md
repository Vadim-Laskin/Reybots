# Приложение «Кабинет РЭУ» (Android)

Каркас на WebView: открывает сайт (кабинет и расписание) и добавляет нативные кнопки
(нижняя панель «Кабинет / Расписание / Бот», меню «Обновить» и «Выйти»).
Вход только через Telegram-бота.

## Запуск
1. Открой папку `android/` в Android Studio (Ladybug или новее, JDK 17), дождись синхронизации Gradle.
2. В `gradle.properties` замени `reyBaseUrl` на адрес своего сайта на Netlify (https, без слэша в конце).
3. Запусти на устройстве или эмуляторе (Android 8.0+).

## Как работает вход
1. Кнопка «Авторизироваться через бота» создаёт запрос на сервере (`/.netlify/functions/appauth`, `init`).
   Секрет остаётся в приложении, на сервер уходит только его SHA-256.
2. Открывается `https://t.me/Armaturchic_bot?start=app_<код>`. Бот проверяет, что человек в группе,
   и присылает кнопку «Подтвердить вход в приложение».
3. Приложение раз в 2 секунды спрашивает сервер (`poll`). После подтверждения оно получает подписанную сессию
   (действует 90 дней), хранит её в зашифрованных настройках и открывает кабинет.
4. Страницы сайта получают сессию из объекта `window.ReyApp` (виден только страницам твоего сайта)
   и шлют её в `cabinet` вместо Telegram initData.

## Сервер
- `BOT_USERNAME` (необязательно): имя бота без @, по умолчанию `Armaturchic_bot`.
- `SESSION_SECRET` (необязательно): ключ подписи сессий, по умолчанию берётся из `BOT_TOKEN`.
  Смена ключа выкидывает всех из приложения.
- Вебхук бота должен принимать `callback_query` (кнопки под сообщением). Если когда-то задавался
  `allowed_updates`, добавь туда `callback_query`.

## Офлайн
- Страницы кабинета и расписания сохраняются в кэше WebView. Один раз их нужно открыть при интернете.
- Ответы сервера (профиль, идеи, домашка, материалы, дни рождения, расписание) сохраняются в хранилище страницы
  (`netlify/public/app-offline.js`, работает только внутри приложения) и показываются без сети. Внизу появляется плашка.
- Без сети можно отправить идею, указать/убрать день рождения, изменить настройку уведомлений: изменение встаёт
  в очередь и уходит, когда интернет вернётся, после чего данные обновляются с сервера.
- Остальные действия (файлы, звуки, админка, ИИ-помощник) требуют интернета.
- Выход из приложения очищает сохранённые данные и очередь.
